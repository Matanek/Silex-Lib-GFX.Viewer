# GFX.Viewer

`GFX.Viewer` displays images, Canvas drawings, Plot figures, and other visual
values in a native window with one `show` call.

```text
silex install GFX.Viewer
```

## Documentation

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

The package requires Silex 0.43.0 or newer.
